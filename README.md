# Parking Garage Fee Calculator

This MIS 310 Python exercise calculates a parking charge from the number of hours parked. It starts with a $5 base charge, adds $2.50 per hour, and applies a $10 minimum and a $20 maximum.

## Run locally

```text
python parking_garage.py
```

Enter the hours as a number. For example, 1 hour costs $10.00, 3 hours costs $12.50, and 8 hours costs $20.00.
