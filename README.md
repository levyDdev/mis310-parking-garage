# Lecture-to-Notes Summarizer

This MIS 310 group final project aims to turn lecture transcripts and text-based PDFs into study notes. This repository currently documents Damon Levy's individual GUI proposal from the Week 9 assignment. The team implementation is pending in this portfolio copy.

## Proposed workflow

1. Enter a lecture title, then paste a transcript or import a text-based PDF.
2. Review the source and select a level of detail and whether to include key terms.
3. Generate notes and compare them with the source in a side-by-side view.
4. Edit the notes and save them as Markdown.

The proposal uses Tkinter for the interface and calls for progress and error messages while processing. Scanned PDFs would require text extraction through OCR before being used as input.
